Welcome to **Vasippu**! This is a clean, responsive, sidebar-driven Jekyll blog theme built for clarity and elegant readability.

<!--more-->

## Features

- **Sidebar Profile Card**: Responsive profile layout with avatar, job title, bio, navigation links, and social icons.
- **Dark / Light Mode Toggle**: Built-in instant theme switcher persisted in local storage.
- **Code Block Copying**: Built-in single-click code copy button for fenced code snippets.
- **Syntax Highlighting**: Beautiful code highlighting using Rouge.
- **Fast & Minimal**: Zero heavy dependencies, pure SCSS layout with responsive flex/grid structure.
