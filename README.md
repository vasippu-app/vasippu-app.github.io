# Vasippu

Vasippu is a clean, minimal, responsive Jekyll blog theme featuring a dynamic sidebar card, light/dark mode switching, Rouge syntax highlighting, and reading time estimation.

## Setup & Running Locally

1. Install dependencies:
   ```bash
   bundle install
   ```

2. Start the Jekyll local dev server:
   ```bash
   bundle exec jekyll serve
   ```

3. Open `http://localhost:4000` in your browser.

## Customization

Edit `_config.yml` to set your site title, bio, social links, and author info.
